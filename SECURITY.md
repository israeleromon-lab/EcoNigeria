# Security Policy

## Supported Versions

Currently, only the `main` branch of EconoNigeria is actively supported with security updates.

## Reporting a Vulnerability

Security is critical to EconoNigeria, especially concerning our automated data pipelines, public APIs, and database integrity.

If you discover a security vulnerability, please do **NOT** open a public issue. 
Instead, please email the core maintainers directly (or open a private security advisory if supported by the repository).

Please include the following in your report:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact on the data infrastructure or API endpoints.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If a fix is required, we will roll out a patch as quickly as possible.

# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased] - EconoNigeria 2.0 (Phase A)

### Changed
- Transitioned project vision from a closed dashboard to an Open Economic Intelligence Infrastructure.
- Complete documentation rewrite to focus on developer ecosystem, APIs, and data provenance.
- Cleaned up technical debt by standardizing "EconoNigeria" naming throughout the repository.
- Re-architected planned data pipelines to support 1-minute real-time ingestion checks for high-frequency data.

### Added
- Standardized open-source community governance files:
  - `CONTRIBUTING.md`
  - `CODE_OF_CONDUCT.md`
  - `SECURITY.md`
  - `ROADMAP.md`

## [1.0.0] - EconoNigeria 1.0 

### Added
- Initial release of the Next.js / FastAPI dashboard.
- Integrated PostgreSQL database for data storage.
- Implemented static ETL pipelines for World Bank and FRED data.
- Basic interactive charting and data visualization for core Nigerian macroeconomic indicators.
